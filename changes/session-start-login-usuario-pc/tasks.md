Usuario PC PRs target the Usuario PC repository mainline only after their Usuario PC prerequisites merge; Dinamizador PRs target the Dinamizador repository mainline only after their Dinamizador prerequisites merge. A PR in one repository that depends on a PR from the other repository records a **cross-repository contract dependency** in OpenSpec/review notes; it MUST NOT use Git branch ancestry across repositories. Each slice keeps the capability disabled by default and must have a clean diff containing only its stated scope. Do not keep dependent PR branches open with predecessor diffs: rebase or recreate each slice from its own repository mainline after its same-repository prerequisites merge. V1 remains parseable for read/transition compatibility, but no privileged v1 mutation may execute without the authenticated, linked, anti-replay path. Automatic/authorized login, autonomy, and PIN reset remain disabled until their named gates below pass.

**Strict TDD evidence required in every PR:** commit or attach (1) a failing focused RED test, (2) the minimum GREEN implementation, (3) TRIANGULATE cases covering the stated edge/failure variants, and (4) a REFACTOR that preserves the focused suite. Tests and documentation ship in the PR they verify.
